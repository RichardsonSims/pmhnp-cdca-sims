# pmhnp-cdca-sims
NURS 5363 PMHNP CDCA simulation stations.

- `sim_case01.html` … `sim_case20.html`: graded cases, standard time (8 / 15 / 7 minutes).
- `extended/sim_case01_extended.html` … `sim_case20_extended.html`: the same cases with time and a half (12 / 22.5 / 10.5 minutes) for approved accommodations.
- `sim_practice.html`: practice case (not graded) with guide cards and a Pause button, so students can learn the layout and check their setup before the exam.
